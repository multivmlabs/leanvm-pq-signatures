# Independent Raccoon benchmark review

Scope: saved direct and recursive Raccoon benchmark receipts, intended-public
statement binding, source and executable identities, and measured work accounting.
The main process owns all proving and VM-measurement workloads. This review does
not run competing provers or modify the frozen guests and runners.

The intended claim is verification of every signature for the caller's ordered
public-key/message pairs under the approved guest. The receiver must pin the
statement and ELF identity from its application. Root verification includes the
ordinary recursive STARK and settlement of all remaining trusted polynomial and
matrix claims. It needs neither signature witnesses nor child proofs.

`binding.py` independently computes leaf commitments with Python `hashlib`,
reconstructs canonical binary-tree padding and the ordered root digest, and
checks its location in the pinned native tree-proof envelope. That public digest
check supplements the production verifier; it does not replace STARK verification.

`consumer_controls.py` exercises the unchanged production receivers from an
isolated directory containing only a root proof and public statement. Recommitted
claim mutations receive fresh statement pins, so rejection cannot be attributed
solely to stale statement hashes. No proofs are generated by this script.

Raccoon-128-1 uses the user-approved official C/Python interoperability policy,
with NIST PDF discrepancies documented. Raccoon-G uses the explicitly identified
strict authors' PoC profile. Its paper conformance and parameter-security analysis
remain outside these benchmark checks. All measurements use plain proof mode.

Original guests: all saved production capacity and direct-proof refusals were
independently checked in `original-rejection-validation.json`. Refusal time is
not an accepted proof benchmark.

The standard optimized guest and its public-only pilot passed the independent
checks in `STANDARD-OPTIMIZED-REVIEW.md`. Its 64 capacity prefixes and 100 leaf
outputs/shapes are checked in `standard-optimized-capacity-validation.json`.

The segmented G guest source, exact final executable, full witness codec and
five-part consumer are reviewed in `SEGMENTED-G-REVIEW.md`. All 14 independent
actual-ELF advice controls pass. `segmented_binding.py` and
`segmented_consumer_controls.py` independently reconstruct the five-part receipt
commitment and test the native public-only receiver, including consistently
recommitted public claim headers. Complete saved tree receipts and the final
three-sample matrix remain to be checked. No estimated points are accepted.


Final status: all 22 complete roots required by the user's reduced sampling
policy pass. G N=100 is one actual producer pipeline, explicitly distinguished
from three-run points and the separate G70-based model. See `MATRIX-REVIEW.md`,
`FINAL-MATRIX-VALIDATION.json` and `G100-ESTIMATE-VALIDATION.json`. Both interrupted
attempt archives and all old source/proof evidence remain preserved. No further
proving was run after the user stopped the remaining repetitions.
